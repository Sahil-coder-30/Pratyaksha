On-Device Model Pipeline — Why Not One Big VLM?

⚠️
The Fatal Trap: Attempting to Run a Single Local VLM in Browser
Some teams will try to load SmolVLM-256M (~500MB) or Moondream2 (~3.7GB) locally via WebAssembly and ask it to find PII. This causes 4–8 second inference latency, crashes browser memory with 1GB+ VRAM consumption, and hallucinates on structured ID numbers. It completely destroys the 20% Resource and 15% Latency rubric scores.
✨

Instead of one slow, bloated generalist VLM, PRATYAKSHA uses a cascade of specialized, INT8-quantized ONNX models running on WebGPU. Each model solves one exact sub-problem with mathematical precision. Total footprint: ~20 MB. Total latency: ~48 ms.

6 Core Innovations & Competitive Moats

INNOVATION 01

Reversible Pseudonymization Vault

Instead of destructive black-box pixel masking (which destroys context and causes VLM hallucination), detected PII is replaced with deterministic typed tokens like ⟨AADHAAR_01⟩. The real value is kept in ephemeral client memory. The server plans using tokens; the client rehydrates locally before typing into the form.

Target: 25% Context + 20% Redaction Rubric
INNOVATION 02

Fail-Closed Dual-Channel Fusion

Merges the Fast DOM Channel (2ms, catches input tags and ARIA labels) with the Deep Vision Channel (45ms, catches PDFs, images, and canvas pixels). If either channel flags a region as sensitive, it is strictly masked. Pages with "SECRET" headers auto-escalate to paranoid mode.

Target: 20% PII Recall (>99% Recall)
INNOVATION 03

Indian Sovereign PII Stack

Verhoeff dihedral checksum eliminates false positives on 12-digit telemetry codes. PAN 4th-character validation ensures entity matching. GSTIN modulo-36 checks, RBI IFSC registry lookup, and Devanagari keyword regex (आधार, गोपनीय, पैन). Built for India, not ported to India.

Target: 20% PII Precision (>98% Precision)
INNOVATION 04

Cryptographic Egress Audit Ledger

Every outbound payload packet is cryptographically hashed in a SHA-256 Merkle chain. The Side Panel provides a live split-screen visual diff: Raw Screen on the left, Sanitized Wire Payload on the right. Judges can verify byte-for-byte that zero raw PII escaped the machine.

Target: Verifiability & Stage WOW Factor
INNOVATION 05

Cascaded 8×8 Dirty-Tile Compute

The 1280×800 viewport is split into 64 tiles (each ~160×100px). A 64-bit perceptual dHash tracks pixel deltas. Unchanged browser tabs, navigation bars, and static headers are cached indefinitely. Only mutated tiles trigger model inference — reducing compute burden by 84%.

Target: 20% Client Resource Utilization
INNOVATION 06

Prompt Injection Hardening & Safety Gate

All web page content is encapsulated inside <untrusted_page_context> XML delimiters. Strict domain allowlists prevent malicious redirection. Destructive actions (SUBMIT, DELETE, APPROVE) enforce a mandatory human approval modal before execution.

Target: Enterprise Defense Credibility

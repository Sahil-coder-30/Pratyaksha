Executive Summary & Core Dilemma

Commercial browser AI agents (OpenAI Operator, Adept, MultiOn, Computer Use) require streaming high-resolution, unredacted desktop screens and entire DOM trees to foreign third-party cloud LLM APIs. In national space missions, defense operations, and sovereign public administration, this represents an intolerable data breach risk and a direct violation of India's Digital Personal Data Protection (DPDP) Act 2023.

⚠️
The Enterprise Core Mandate
Sensitive citizen identity (Aadhaar, PAN, Voter ID), defense credentials, internal telemetry, and employee sessions must be sanitized on-device inside the browser client before any network byte is emitted. Only anonymized visual context and synthetic token identifiers may leave the client device.

PRATYAKSHA solves this through a lightweight (~20MB total footprint) on-device neural vision stack compiled to WebGPU via ONNX Runtime Web. It runs inside an isolated browser Offscreen Document, pairing deep neural text and face detectors with deterministic Indian PII validators (Verhoeff checksum for Aadhaar, modulo-36 for GSTIN). The server VLM reasons using synthetic tokens (⟨AADHAAR_01⟩), and the local agent executes actions securely without ever exposing sensitive data.

Our 5 Core Technical Innovations

🔐
Reversible Pseudonym Vault
Instead of destructive black-box redaction, PRATYAKSHA generates typed tokens like ⟨AADHAAR_01⟩ and preserves their bounding box geometry. The server VLM can reference these tokens in actions, and the client securely rehydrates the real value into form fields right before dispatching keyboard events.
🛡️
Fail-Closed Dual-Channel Fusion
Combines structural DOM priors with neural pixel-level DBNet text detection. If DOM analysis misses a canvas signature, scanned PDF, or shadow DOM field, the WebGPU vision channel catches it. If either channel flags sensitive data, redaction is triggered immediately.
🇮🇳
Sovereign Indian PII Stack
Hardened against Indian governmental formats: Verhoeff algorithm for 12-digit Aadhaar validation (eliminates false positives from serial numbers), PAN structure validator, GSTIN modulo-36 checksum, RBI IFSC routing table, and multilingual Devanagari OCR models.
🧾
Cryptographic Egress Ledger
Every single frame and JSON payload transmitted to the server is hashed with SHA-256 and appended to a tamper-proof in-memory Merkle chain. Users and security auditors can open the Side Panel HUD to verify the exact split-screen diff of what left the browser.
